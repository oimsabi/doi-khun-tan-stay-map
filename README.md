# Doi Khun Tan Stay Map

เว็บภาษาไทยหน้าเดียวสำหรับสำรวจบ้านพักดอยขุนตาล เปรียบเทียบที่พัก และวางงบสำหรับเดินทางไป ย.4

**เว็บไซต์:** https://doi-khun-tan-stay-map.sittan-rattanaliam.chatgpt.site (จำกัดการเข้าถึงตามสิทธิ์ของ Sites)

## ความสามารถ

- ใช้แผนที่ต้นฉบับ 9,000 × 6,300 px อัตราส่วน 10:7 พร้อมเลื่อนและซูม
- คลิกบ้าน 301, 303, 304, 401–405, 410 และ 502 เพื่อดูรูป ราคาอ้างอิง ความจุ และสิ่งอำนวยความสะดวก
- แยกลานสน ย.2 ออกจากลานพักแรม 2
- เลือกบ้านหลายหลัง รวมราคา ความจุ ห้องนอนและห้องน้ำ พร้อมแจ้งเมื่อจำนวนที่พักไม่พอ
- ปรับจำนวนคน จำนวนคืน และอุปกรณ์เต็นท์ โดยไม่คิดค่าพื้นที่ซ้ำ
- รองรับคอมพิวเตอร์และมือถือ และจำรายการที่เลือกด้วย localStorage ในเบราว์เซอร์

## เปิดใช้งาน

ไม่มี dependencies และไม่มีขั้น build เปิด `dist/index.html` ในเบราว์เซอร์ได้โดยตรง

หากต้องการเว็บเซิร์ฟเวอร์ในเครื่อง และติดตั้ง Python แล้ว:

```sh
python -m http.server 8000 --directory dist
```

จากนั้นเปิด http://localhost:8000

## ทดสอบ

ต้องมี Node.js:

```sh
node --check dist/app.js
node checks.cjs
```

การทดสอบครอบคลุมข้อมูลบ้านทั้ง 10 หลัง ไฟล์รูป ความจุ การเลือกซ้ำ จำนวนคืน การปัดจำนวนเต็นท์ และค่าอุปกรณ์/พื้นที่ นอกจากนี้ได้ทดสอบการเปิดรายละเอียดบ้าน จุดคลิก ซูม การเลือกบ้านหลายหลัง และการแสดงผลมือถือบนเว็บที่เผยแพร่แล้ว

## โครงสร้าง

```text
dist/
  index.html       หน้าเว็บ
  style.css        รูปแบบและ responsive layout
  data.js          ข้อมูลที่พักและจุดบนแผนที่
  model.js         สูตรคำนวณงบและความจุ
  app.js           การโต้ตอบและแผนที่
  sources.json     แหล่งข้อมูลที่ตรวจสอบ
  assets/          แผนที่ รูปบ้าน และฟอนต์
checks.cjs         การทดสอบสูตรคำนวณและข้อมูล
.openai/hosting.json  การผูกกับ Sites เดิม
```

## การแก้ไขข้อมูล

แก้รายการใน `dist/data.js` ซึ่งเป็นข้อมูลชุดเดียวที่ใช้ในแผนที่ รายละเอียด และส่วนเปรียบเทียบ จุด `x` และ `y` เป็นสัดส่วน 0–1 ของภาพแผนที่ทั้งภาพ ไม่ใช่พิกัด GPS หากเพิ่มรูปให้เก็บใน `dist/assets/` และระบุแหล่งที่มา

## แหล่งข้อมูลและข้อจำกัด

- รายละเอียดบ้านและรูปภาพ: หน้าบ้านพักแต่ละหลังของกรมอุทยานแห่งชาติฯ ตรวจเมื่อ 13 ตุลาคม 2569 ลิงก์ต้นทางอยู่ในข้อมูลของแต่ละหลัง
- แผนที่: ภาพ `doi-khun-tan-reference-9000.png` จากงานที่ผู้ใช้ส่งอ้างอิง ปรับจาก PDF และคงสัดส่วน 10:7 เป็นผังตำแหน่งสัมพัทธ์ ไม่ใช่มาตราส่วนจริง
- ราคาที่พัก ค่าเต็นท์ และระยะจากบ้านถึง ย.4 เป็นข้อมูลอ้างอิงจากแผนเดิม ยังไม่ยืนยันอัตราปัจจุบันหรือระยะ GPS รายหลัง
- คะแนนความสบายเป็นการประเมินเพื่อช่วยเปรียบเทียบ ไม่ใช่คะแนนรีวิวผู้เข้าพัก
- ภาพจาก DNP อาจเป็นภาพเก่า และภาพสิ่งอำนวยความสะดวกบางภาพถูกใช้ร่วมกันหลายหลัง
- ไม่มีระบบจอง ข้อมูลห้องว่างสด หรือระบบหลังบ้าน ตรวจราคาและเงื่อนไขกับอุทยานฯ ก่อนจอง
- รูปภาพ แผนที่ และฟอนต์เป็นทรัพย์สินของเจ้าของเดิม การเก็บไว้ใน repository นี้ไม่ได้เปลี่ยนสิทธิ์ของเจ้าของ

## เผยแพร่

นำเนื้อหาใน `dist/` ขึ้น static hosting ได้ หรือใช้ Sites ตาม `.openai/hosting.json` หากนำไปสร้าง Site ใหม่ ให้ลงทะเบียน Site ใหม่และใช้ project ID ที่ได้รับ ไม่ควรนำ ID ของ Site เดิมไปใช้กับโปรเจกต์อื่น
